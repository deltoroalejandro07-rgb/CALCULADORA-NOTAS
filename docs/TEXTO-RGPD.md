## 2. Cómo lo registra el CRM

- Al registrar la visita (o desde la ficha → *Comunicaciones comerciales*) el comercial marca el canal aceptado. Queda guardado **con fecha, usuario y forma** (de palabra, hoja firmada…) y **no se puede editar**: un cambio es un registro nuevo.
- Sin consentimiento en un canal, la base de datos **impide** preparar o registrar mensajes por ese canal.
- Cada mensaje comercial lleva el aviso de baja. Si un cliente responde *BAJA*, regístralo en su ficha → *Registrar baja*.
- **Derecho de acceso/portabilidad:** ficha del cliente → *Exportar todos los datos de este cliente (RGPD)*.
- **Derecho de supresión:** administrador → editar cliente → *Borrar cliente y sus datos* (borra también visitas, fotos, mensajes y pedidos).
